# OD709 unsafe-deserialization-flow

Data a user controls is loaded by pickle, marshal or an unsafe YAML loader.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Security | Error | all | no |

## What it reports

A value from a [source](https://avanserv.github.io/odooscan/rules/#od7-data-flows) that reaches
`pickle.loads()`, `pickle.load()`, `marshal.loads()`, `marshal.load()`, `yaml.unsafe_load()` or
`yaml.unsafe_load_all()`, or `yaml.load()` and `yaml.load_all()` with a loader other than
`SafeLoader`, `CSafeLoader`, `BaseLoader` or `CBaseLoader`, or with none.

The `pickle` that `odoo.tools` exports up to 17.0 is not reported: it refuses every class but a few
plain ones, so it loads data and runs nothing. A call is read as that one whenever its first name
comes from an import of `odoo`, as `pickle` does after `from odoo.tools import pickle`.

## Why it matters

A pickle names the functions to call to rebuild its objects, and loading it calls them: a user who
sends one runs any code as the user of the server. A YAML loader other than a safe one builds
objects of any class the document names, with the same result. `marshal` was never meant for data
from outside, and crashes the server on a crafted value.

## Example

```python title="controllers/main.py"
class Cart(http.Controller):
    @http.route("/shop/cart/restore", type="http", auth="user")
    def restore(self, saved):
        lines = pickle.loads(base64.b64decode(saved))
        return request.render("shop.cart", {"lines": lines})
```

`saved` may be a pickle that calls `os.system()` while it loads.

```python title="controllers/main.py"
class Cart(http.Controller):
    @http.route("/shop/cart/restore", type="http", auth="user")
    def restore(self, saved):
        lines = json.loads(base64.b64decode(saved))
        return request.render("shop.cart", {"lines": lines})
```

JSON holds values only, so loading it runs nothing.

## Suppressing

```python
data = pickle.loads(blob)  # odooscan: ignore[OD709]
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
