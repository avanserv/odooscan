# OD140 super-in-class-body

super() without arguments runs in a class body, where it has no class or instance, so it raises.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Correctness | Error | all | no |

## What it reports

A `super()` call with no argument that runs while a class body runs: one among the class's own
statements, such as `x = super().name()`, in a comprehension or generator expression there, in
the decorators, defaults and annotations of its methods, in the head of a class it nests, or in the
defaults of a lambda there. Any class counts, a model or one defined inside a method.

Annotations count unless the file has `from __future__ import annotations`: every series supports a
Python before 3.14, which evaluates them as the class body runs.

A call in the body of a method or a lambda is not reported, since it runs later in a function, nor
is `super(Class, obj)`, which names what it needs, nor one in a `type` alias, whose value and
type-parameter bounds run only when read. Nothing is reported in a file that binds the name `super`
anywhere, such as with `from compat import super`, a `case super:` capture or a `class A[super]`
type parameter, since the call may not be the builtin. A `super()` call at module level, or in a
function outside any class, is not reported though it raises too.

## Why it matters

A zero-argument `super()` takes its class from the `__class__` cell Python gives a function in a
class body that calls it, and its instance from that function's first argument. Run as a class body
runs, it has no class or instance to take and raises `RuntimeError`: for a model when Odoo imports
the module, for a class defined in a method each time the method runs.

A generator expression raises only once iterated. Consumed in the class body, as in
`tuple(super().name() for ...)`, it raises `RuntimeError` up to Python 3.11 and `NameError` from
3.12. Iterated after the class exists, it takes the generator's iterator for the instance and
raises `TypeError`.

## Example

```python title="models/res_partner.py"
from odoo import fields, models


class ResPartner(models.Model):
    _inherit = "res.partner"

    type = fields.Selection(super()._fields["type"].selection + [("vip", "VIP")])
```

```python title="models/res_partner.py"
from odoo import fields, models


class ResPartner(models.Model):
    _inherit = "res.partner"

    type = fields.Selection(selection_add=[("vip", "VIP")], ondelete={"vip": "set default"})
```

## Suppressing

```python
type = fields.Selection(super()._fields["type"].selection)  # odooscan: ignore[OD140]
```
