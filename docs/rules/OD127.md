# OD127 get-route-writes

An HTTP route that accepts GET writes records, which Odoo checks no CSRF token for.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Security | Warning | all | no |

## What it reports

An `@http.route` with a URL, of type `http` (the default), that accepts `GET` and whose body calls
`write()`, `create()` or `unlink()` on records. A route accepts `GET` when it has no `methods`, or
when its literal `methods` list holds `"GET"`. Records are what `request.env[...]`,
`request.env.user` and `request.env.ref()` give, the result of `sudo()`, `browse()`, `search()`
and the like on them, their fields, the names bound to any of these, and the parameters a `model`
or `models` converter of the URL fills.

It stays silent when:

- the write runs only under a test that the request method is one Odoo checks, such as
  `if request.httprequest.method == "POST":`;
- the body checks a token itself, with `validate_csrf()`, `consteq()`, `hmac.compare_digest()` or
  `check_access_token()`;
- the route passes `csrf=False`, which [OD112](OD112.md) reports;
- the route has no URL: an override keeps the routing of the route it overrides, so its methods
  are not known from its own decorator;
- `type` is not a literal, or `methods` is not a literal list or tuple.

Only the route's own body is read, with the functions it nests, so a write in a helper it calls is
not reported.

## Why it matters

Odoo checks the `csrf_token` of an `http` route only on methods that may change data: `GET`,
`HEAD`, `OPTIONS` and `TRACE` pass unchecked. Any page the user visits can make their browser
request a `GET` URL, with an `<img>` tag or a link, and the request carries their session cookie.
A route that writes on `GET` therefore writes on behalf of whoever opens that page.

## Example

```python title="controllers/main.py"
class SubscriptionController(http.Controller):
    @http.route("/my/newsletter/stop", type="http", auth="user")
    def stop_newsletter(self):
        request.env.user.partner_id.write({"newsletter": False})
        return request.redirect("/my")
```

Any site the user visits can embed `<img src="https://odoo.example.com/my/newsletter/stop">` and
unsubscribe them.

```python title="controllers/main.py"
class SubscriptionController(http.Controller):
    @http.route("/my/newsletter/stop", type="http", auth="user", methods=["POST"])
    def stop_newsletter(self):
        request.env.user.partner_id.write({"newsletter": False})
        return request.redirect("/my")
```

The form that posts to the route sends `csrf_token`, as a hidden input set to
`request.csrf_token()`.

## Suppressing

```python
def stop_newsletter(self):  # odooscan: ignore[OD127]
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
