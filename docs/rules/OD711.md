# OD711 header-injection-flow

Data a user controls reaches the headers of a response.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Security | Warning | all | no |

## What it reports

A value from a [source](https://avanserv.github.io/odooscan/rules/#od7-data-flows) that reaches
the `headers` of `request.make_response()`, `request.make_json_response()` or `Response()`, by
keyword or position, any argument of `headers.add()` or `headers.set()`, or a header set as
`response.headers[name] = value`.

The headers of an outgoing client are skipped, as they go out with the requests it sends: a local
or an attribute of `self` that the function binds to `requests.Session()`, `requests.session()`,
`httpx.Client()` or `httpx.AsyncClient()`, one of those calls used as the receiver itself, the
target of a `with` on one of them, and a receiver whose name holds `session`.

A file name passed through `content_disposition()` is harmless: it quotes the name, so that it
ends no parameter of `Content-Disposition`. The parameters of a route that a `model` or `models`
converter fills in every URL, as `<model("ir.attachment"):attachment>`, are records, whose fields
the user does not pick. A URL that leaves one out lets the query string give it any value.

## Why it matters

A header the user picks tells the browser how to read the response: `text/html` as the
`Content-Type` of a download runs the user's script on the site, and a name with `;` or `"` in
`Content-Disposition` adds parameters, such as another file name. Werkzeug refuses a newline in
a header, so no header is added and no response is split, which is why the rule warns rather than
errors.

## Example

```python title="controllers/main.py"
class Exports(http.Controller):
    @http.route("/shop/export", type="http", auth="user")
    def export(self, name):
        headers = [("Content-Disposition", f"attachment; filename={name}")]
        return request.make_response(self._csv(), headers)
```

`name` may be `x.html; filename*=UTF-8''x.html`, which the browser prefers.

```python title="controllers/main.py"
class Exports(http.Controller):
    @http.route("/shop/export", type="http", auth="user")
    def export(self, name):
        headers = [("Content-Disposition", content_disposition(name))]
        return request.make_response(self._csv(), headers)
```

`content_disposition()` quotes the name.

## Suppressing

```python
return request.make_response(data, headers)  # odooscan: ignore[OD711]
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
