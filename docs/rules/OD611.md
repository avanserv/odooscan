# OD611 console-log

A script a page loads calls `console.log()`.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Quality | Info | all | no |

## What it reports

A call `console.log(...)` in every script a bundle loads but those under `static/tests`.
`console.warn`, `console.error` and a `log()` method of any other object are not reported. Neither is
a call ESLint is told to accept, as it reads its comments: an
`// eslint-disable-next-line no-console` on the line before, an `// eslint-disable-line no-console`
on the line of the call, or a call between `/* eslint-disable no-console */` and
`/* eslint-enable no-console */` or the end of the file. A comment that names no rule covers every
rule, this one included.

## Why it matters

A `console.log()` is usually a debugging leftover. It writes to the console of every user, where it
buries the warnings and errors that matter when a user reports a problem, and it may print record
data that has no place there. A message that must reach the console is a warning or an error, and
says so with `console.warn()` or `console.error()`.

## Example

```js title="static/src/js/order_line.js"
onQuantityChange(quantity) {
    console.log("quantity", quantity, this.props.record.data);
    this.props.record.update({ product_uom_qty: quantity });
}
```

Every change of quantity prints the whole line to the console.

```js title="static/src/js/order_line.js"
onQuantityChange(quantity) {
    this.props.record.update({ product_uom_qty: quantity });
}
```

## Suppressing

```js
// eslint-disable-next-line no-console
console.log("Tour finished");
```

ESLint's own comment silences the finding too, or else:

```js
// odooscan: ignore[OD611]
console.log("Tour finished");
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
