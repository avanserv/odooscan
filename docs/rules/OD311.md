# OD311 unknown-qweb-template

A QWeb view calls a template no module in scope defines.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Correctness | Error | all | yes |

## What it reports

A literal `t-call="x"`, or an `<attribute name="t-call">` that sets one, in a `<template>` or a
QWeb `ir.ui.view` of a data file the manifest loads, when no module in the module's scope defines
`x`. A view defines `x` by its full XML id or its `key`. A template that only a module missing from
`depends` defines is reported too, naming that module. A module that Odoo always installs with
`base`, such as `web`, counts as in `depends`.

The rule matches the whole name, so an undotted target finds a `key` and nothing else: the module
of the view is never added to it.

## Why it matters

Odoo looks the target up when the `t-call` runs, and a target it cannot find fails the render. The
install does not check the name, so the error reaches the user who opens the report or the page, and
a `t-call` under a `t-if` only fails when that branch runs. When the template comes from a module
outside `depends`, the page renders where that module is installed and breaks where it is not.

The rule leaves alone what only a render can tell: an expression such as `{{ x }}` or `#{x}`, a
numeric view id, and a path to an `.xml` file. A kanban arch runs its `t-call` in the web client,
against the templates of its own arch, so a view whose inheritance tree starts at a non-QWeb view
is not checked. For a module whose dependencies include one that is not indexed, such as an
Enterprise module, the rule stays silent on a target whose prefix names no indexed module. Targets
in Owl templates under `static/src` are [OD605](OD605.md)'s.

## Example

```xml title="views/portal_templates.xml"
<template id="portal_invoice">
    <t t-call="web.basic_layot">
        <div class="page">Invoice</div>
    </t>
</template>
```

The template is `web.basic_layout`, so the page fails as soon as it renders.

```xml title="views/portal_templates.xml"
<template id="portal_invoice">
    <t t-call="web.basic_layout">
        <div class="page">Invoice</div>
    </t>
</template>
```
