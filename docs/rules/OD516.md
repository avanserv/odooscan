# OD516 python-file-not-imported

A file of models or controllers is never imported, so Odoo never loads them.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Correctness | Warning | all | no |

## What it reports

A Python file of the module that defines a model class or a controller, one with a route or with
Odoo's `Controller` among its bases or those of a class of the file it extends, when no chain of
imports from the module's root `__init__.py` reaches it. The finding is on the file's first line
and names the first model or controller.

An import reaches a file wherever it sits in the importer, a function or a `try` block included,
and through every form Python reads: relative imports at any level, `odoo.addons.<module>` and
`openerp.addons.<module>`, a package without `__init__.py`, a star import of the names
`__all__` lists, and a plain `import models` on 9.0 and 10.0, which Python 2 reads as relative. A
file another module imports is loaded with that module, so it is not reported either.

Files under `tests/`, which [OD517](OD517.md) covers, `migrations/` and `upgrades/` are left out,
and so are those under `iot_handlers/`, which the IoT box loads by their path.
Nothing is reported for a module without a root `__init__.py`, one with a Python file the scan
cannot decode, or when an import on the way computes the name of what it imports, loads a file by
its path or does not parse, since any file may then be loaded.

## Why it matters

Loading a module imports `odoo.addons.<module>`, which runs the root `__init__.py` and only what it
imports in turn. A model in a file nothing imports is never registered: its table is not created,
and the views, access rows and data that name it fail to load. A controller there serves none of
its routes. The usual cause is a new file left out of its package's `__init__.py`.

## Example

```python title="models/__init__.py"
from . import library_book
```

`models/library_loan.py` defines `library.loan`, but nothing imports it, so the model does not
exist.

```python title="models/__init__.py"
from . import library_book
from . import library_loan
```

## Suppressing

The finding is on the file's first line, so a trailing comment there covers it:

```python
from odoo import fields, models  # odooscan: ignore[OD516]
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
