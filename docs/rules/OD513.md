# OD513 asset-path-unmatched

An assets path or glob of the module matches no file Odoo serves.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Correctness | Warning | saas~14.3 and later | no |

## What it reports

A path or glob of a bundle under the manifest's `assets` that names the module itself and
resolves to no file:

- a glob matching no `js`, `css`, `scss`, `sass`, `less` or `xml` file under the module's
  `static/`;
- a path without a wildcard, ending in one of those extensions, to a file that does not exist;
- from saas~16.3, a path or glob outside the module's `static/`;
- before saas~16.3, an `xml` path or glob outside the module's `static/`, unless a wildcard in
  its first directory may reach `static/`.

Every entry is checked but an `include`, which names a bundle: a plain one, and the path of an
`after`, `before`, `prepend`, `remove` or `replace` one. URLs, paths into other modules and a
missing file of another extension, such as a font, are not reported.

## Why it matters

Odoo expands each glob against the disk when it builds a bundle. A glob that matches nothing
adds nothing and only logs `did not resolve to anything`, so the scripts, styles or templates the
module meant to load are missing in the browser. A path without a wildcard is kept as a URL, which
the bundle then fails to load. From saas~16.3 Odoo serves files under `static/` alone, so a path
elsewhere in the module resolves to nothing either. Before saas~16.3, Odoo refuses templates
outside `static/` so that they cannot leak data. The cause is usually a typo in a directory name or
a file moved without updating the manifest.

## Example

```python title="__manifest__.py"
{
    "name": "Library loans",
    "version": "18.0.1.0.0",
    "depends": ["web"],
    "license": "LGPL-3",
    "assets": {
        "web.assets_backend": ["library_loan/static/src/jss/**/*"],
    },
}
```

The scripts are under `static/src/js`, so the glob matches nothing. Fix the directory:

```python title="__manifest__.py"
{
    "name": "Library loans",
    "version": "18.0.1.0.0",
    "depends": ["web"],
    "license": "LGPL-3",
    "assets": {
        "web.assets_backend": ["library_loan/static/src/js/**/*"],
    },
}
```

## Suppressing

```python
"web.assets_backend": ["library_loan/static/src/jss/**/*"],  # odooscan: ignore[OD513]
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
