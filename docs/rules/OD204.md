# OD204 missing-method

A field's `compute`, `inverse` or `search` names a method the model does not have.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Correctness | Error | all | yes |

## What it reports

A field whose `compute`, `inverse` or `search` is a string naming a method that no class of the
model defines, in this module or in its dependencies. Methods inherited through `_inherit` and
`_inherits` count, and so do `_compute_display_name` and `_search_display_name`, which every model
has.

## Why it matters

Odoo looks the method up by name only when it needs it, so the registry loads and the error waits:
a stored computed field is computed for the existing records while the module installs, and the
install fails with `AttributeError`. A field that is not stored fails on its first read, from a
view or from code; an `inverse` fails on the first write and a `search` on the first search on the
field.

A related field is left alone, because Odoo replaces its compute and inverse with its own. A method
passed as a function rather than a name is not checked: Python already refuses a name that does
not exist when it imports the file. A method that only a module missing from `depends` defines
counts as missing, since that module may not be installed.

## Example

```python title="models/sale_order.py"
class SaleOrder(models.Model):
    _inherit = "sale.order"

    total_weight = fields.Float(compute="_compute_total_weight")

    @api.depends("order_line.product_id.weight", "order_line.product_uom_qty")
    def _compute_weight(self):
        for order in self:
            order.total_weight = sum(
                line.product_id.weight * line.product_uom_qty for line in order.order_line
            )
```

The field names `_compute_total_weight`, but the method is called `_compute_weight`.

```python title="models/sale_order.py"
class SaleOrder(models.Model):
    _inherit = "sale.order"

    total_weight = fields.Float(compute="_compute_total_weight")

    @api.depends("order_line.product_id.weight", "order_line.product_uom_qty")
    def _compute_total_weight(self):
        for order in self:
            order.total_weight = sum(
                line.product_id.weight * line.product_uom_qty for line in order.order_line
            )
```

## Suppressing

```python
total_weight = fields.Float(compute="_compute_total_weight")  # odooscan: ignore[OD204]
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
