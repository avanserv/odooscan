# OD203 unresolved-field-path

A field path does not resolve on its model.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Correctness | Error | all | yes |

## What it reports

A dotted field path, followed one field at a time from its model, names a field that does not
exist, a field from a module missing from `depends`, or continues past a field that is not
relational. The paths checked are those given to `@api.depends`, `@api.onchange` and
`@api.constrains`, a field's `related`, a One2many's inverse name, and the fields named in
`_order` and `_rec_name`. A module that Odoo always installs with `base`, such as `web`, counts as
in `depends`.

## Why it matters

Odoo follows `related` and `@api.depends` paths when it builds the registry, and a field that is
not there stops the registry from loading: the module cannot be installed, and a database that
already has it fails to start. A bad `_order` or `_rec_name` waits until the first search or name
lookup on the model. A path that reaches a field only through a module missing from `depends`
works in a database where that module happens to be installed and fails in one where it is not.

The rule stops at what it cannot see: a path through a model no indexed module defines, or through
a field whose value has no fixed model (`Reference`, `Many2oneReference`, `Properties`, `Json`),
counts as resolved. Paths in an abstract model are not checked, because they name fields of the models that
inherit it.

## Example

```python title="models/sale_order.py"
class SaleOrder(models.Model):
    _inherit = "sale.order"

    partner_country_code = fields.Char(related="partner_id.country_id.cde")
    label = fields.Char(compute="_compute_label")

    @api.depends("partner_id.name.size")
    def _compute_label(self):
        ...
```

`res.country` has no `cde` field, and `name` is a `Char`, so the second path cannot go past it.

```python title="models/sale_order.py"
class SaleOrder(models.Model):
    _inherit = "sale.order"

    partner_country_code = fields.Char(related="partner_id.country_id.code")
    label = fields.Char(compute="_compute_label")

    @api.depends("partner_id.name")
    def _compute_label(self):
        ...
```

When the field comes from a module the path crosses, add that module to `depends` in
`__manifest__.py`.

## Suppressing

```python
partner_country_code = fields.Char(related="partner_id.x_code")  # odooscan: ignore[OD203]
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
