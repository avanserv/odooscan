# OD508 license-unknown

The manifest names a license Odoo does not know, which fails the module list update.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Correctness | Error | all | no |

## What it reports

A `license` that is not one of the values of `ir.module.module`'s license field: `GPL-2`,
`GPL-2 or any later version`, `GPL-3`, `GPL-3 or any later version`, `AGPL-3`, `LGPL-3`,
`Other OSI approved licence`, `OEEL-1`, `OPL-1` or `Other proprietary`. 9.0 lacks `OPL-1`. The
comparison is exact, so `lgpl-3` or `LGPL-3.0` is reported too.

## Why it matters

Odoo copies the license of each manifest into the apps list when it updates the list: on an
install or update from the command line, and from Apps, Update Apps List. A value outside the
selection fails that write with `Wrong value for ir.module.module.license`, which stops the update
of the whole list. Licenses of other ecosystems, such as `MIT` or `Apache-2.0`, go under
`Other OSI approved licence`.

## Example

```python title="__manifest__.py"
{
    "name": "Library loans",
    "version": "18.0.1.0.0",
    "depends": ["base"],
    "license": "MIT",
}
```

Odoo knows no `MIT` license. Use the value that covers it:

```python title="__manifest__.py"
{
    "name": "Library loans",
    "version": "18.0.1.0.0",
    "depends": ["base"],
    "license": "Other OSI approved licence",
}
```

## Suppressing

```python
"license": "MIT",  # odooscan: ignore[OD508]
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
