# OD512 data-file-repeated

A file is listed twice under data or demo, so Odoo loads it twice.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Correctness | Warning | all | no |

## What it reports

An entry of the manifest's `data` or `demo` naming a file an earlier entry of the same list
names, on the later entry. Entries are compared as paths, so `./views/a.xml` repeats
`views/a.xml`.

## Why it matters

Odoo loads each entry in turn, so the file loads a second time, after the files listed between
the two entries. Records it creates are written again and may overwrite what those files changed,
a CSV file is imported twice, and an SQL file runs twice. Odoo only logs
`File ... is imported twice` when the two entries are written the same way. The repeat is usually
a file moved within the list, with the old line left behind.

## Example

```python title="__manifest__.py"
{
    "name": "Library loans",
    "version": "18.0.1.0.0",
    "depends": ["base"],
    "license": "LGPL-3",
    "data": [
        "security/ir.model.access.csv",
        "views/library_loan_views.xml",
        "data/library_loan_data.xml",
        "views/library_loan_views.xml",
    ],
}
```

Keep the entry at the place the file must load:

```python title="__manifest__.py"
{
    "name": "Library loans",
    "version": "18.0.1.0.0",
    "depends": ["base"],
    "license": "LGPL-3",
    "data": [
        "security/ir.model.access.csv",
        "views/library_loan_views.xml",
        "data/library_loan_data.xml",
    ],
}
```

## Suppressing

```python
"views/library_loan_views.xml",  # odooscan: ignore[OD512]
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
