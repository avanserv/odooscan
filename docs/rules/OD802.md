# OD802 translation-fuzzy

A translation is marked fuzzy, yet Odoo loads it as a reviewed one.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Quality | Info | all | no |

## What it reports

An entry of a `.po` file in `i18n/` or `i18n_extra/` whose `#,` flags hold `fuzzy` and which has a
translation. The header, a fuzzy entry without a translation, and an entry Odoo drops as obsolete
are not reported. When the folder of the `.po` file holds the module's template, such as
`i18n/sale_kiosk.pot`, an entry the template lacks is obsolete, as Odoo merges the two before
loading the catalog.

## Why it matters

gettext marks an entry fuzzy when it guesses the translation from a similar message, for a
translator to check. Odoo skips only obsolete entries (18.0 `odoo/tools/translate.py:830`, 20.0
`:1411`), those written with `#~` or, once it merges the module's template into the catalog
(18.0 `:800-826`, 20.0 `:1381-1407`), those the template lacks. It loads a fuzzy translation as any
other: users read the guess, which may say something other than the message or carry other
placeholders.

## Example

```po title="i18n/fr.po"
#. module: sale_kiosk
#: model:ir.model.fields,field_description:sale_kiosk.field_sale_order__x_kiosk_id
#, fuzzy
msgid "Kiosk"
msgstr "Kiosque de vente"
```

```po title="i18n/fr.po"
#. module: sale_kiosk
#: model:ir.model.fields,field_description:sale_kiosk.field_sale_order__x_kiosk_id
msgid "Kiosk"
msgstr "Kiosque"
```

## Suppressing

```po
# odooscan: ignore[OD802]
#, fuzzy
msgid "Kiosk"
msgstr "Kiosque de vente"
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
