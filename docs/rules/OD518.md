# OD518 python-import-not-in-depends

A Python import names a module outside depends, which may be missing or load later.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Correctness | Warning | all | yes |

## What it reports

An import of a module by its path under `odoo.addons` or `openerp.addons`, or by a relative path
that climbs past the importing module's root, when that module is not in the importer's
dependencies. The dependencies are those in `depends`, the modules they depend on in turn, and
`base`; a module that Odoo always installs with `base`, such as `web`, counts as in `depends`. The
finding is on the module path after `from`, or on the name of a plain `import`, and names the
module. A module that is not indexed at all is reported too, since `depends` cannot reach it.

The rule leaves out an import Odoo does not run as the module loads: one in a function, one in a
`try` that catches `ImportError` or `ModuleNotFoundError`, one under `contextlib.suppress()` or
`if TYPE_CHECKING:`, and any in a file under `migrations/`, `upgrades/` or `iot_handlers/`. It
stays silent when a dependency that is not indexed, such as an Enterprise module, could depend on
the module imported. Add the checkout of that dependency to `--addons-path` to check the imports.

## Why it matters

Every module on the addons path is importable, so the import itself works on the server where the
other module sits beside this one, and fails with `ModuleNotFoundError` where it does not: the
module then fails to load. A module outside `depends` may also be uninstalled, or load after this
one. Its models are then not in the registry, so a class imported from it is not the model Odoo
runs, and importing it early skips its `post_load` hook. The code works in a database where the
other module happens to be installed and loaded first, and breaks on a fresh one.

## Example

```python title="__manifest__.py"
"depends": ["sale"],
```

```python title="models/sale_order.py"
from odoo.addons.project.models.project_task import ProjectTask
```

`project` is not among the dependencies of `sale`.

```python title="__manifest__.py"
"depends": ["sale", "project"],
```

## Suppressing

```python
from odoo.addons.project.models.project_task import ProjectTask  # odooscan: ignore[OD518]
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
