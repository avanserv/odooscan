# OD103 cursor-commit

Business code commits the cursor, breaking the request's transaction.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Correctness | Warning | all | no |

## What it reports

A call to `commit()` on the request's cursor: `cr.commit()`, `self.env.cr.commit()` or
`self._cr.commit()`.

## Why it matters

Odoo runs each request, cron job and RPC call in one transaction: it commits when the call ends and
rolls everything back when it raises. A commit in the middle makes the work done so far permanent,
so an error later leaves half of the operation applied and the user is told it failed. Odoo also
retries a whole request when PostgreSQL reports a concurrent update, and the retry repeats the
committed work, sending the same message or creating the same record twice.

Committing on purpose has its place, such as a cron job that processes a large batch and keeps its
progress when a later record fails; from 19.0, `ir.cron`'s `_commit_progress()` does that. Review
such a call and suppress the finding on its line. A cursor opened with `self.pool.cursor()` under
another name, such as `new_cr`, is its own transaction and is not reported.

## Example

```python title="models/product_template.py"
class ProductTemplate(models.Model):
    _inherit = "product.template"

    def action_push_prices(self):
        for template in self:
            template._send_price_to_shop()
            template.x_price_pushed_on = fields.Datetime.now()
            self.env.cr.commit()
```

If the third template fails, the first two stay marked as pushed while the user sees an error.

```python title="models/product_template.py"
class ProductTemplate(models.Model):
    _inherit = "product.template"

    def action_push_prices(self):
        for template in self:
            template._send_price_to_shop()
            template.x_price_pushed_on = fields.Datetime.now()
```

## Suppressing

```python
self.env.cr.commit()  # odooscan: ignore[OD103]
```

See [suppressing a finding](https://github.com/avanserv/odooscan#suppressing-a-finding).
