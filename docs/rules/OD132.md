# OD132 translation-at-import

_() runs at import, where no language is known, so the text is never translated.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Quality | Warning | all | no |

## What it reports

A call to `_()` that runs when Python imports the file, in a file that imports `_` from `odoo` or a
module under it: at module level, in a class body, or in a comprehension there, such as a module
constant `ERROR = _("Invalid order")` or a field attribute `string=_("Note")`. A call in a function
or a lambda runs when it is called and is not reported, nor is one through another name, such as
`self.env._()`, nor a `_` that names `_lt`, such as `from odoo.tools.translate import _lt as _`.

The whole `def` or `lambda` counts as deferred, so a call in a decorator or a parameter default,
such as `def f(self, label=_("Note"))` or `lambda x=_("a"): x`, is not reported, though it runs at
import too.

## Why it matters

`_()` translates into the language it finds in the caller's `context`, in the environment of its
`self`, or in the current request (`odoo/tools/translate.py`, `_get_lang()`). At import there is
none of them: it logs a warning and returns the source text, which the module then keeps for good.
Every user sees that English text, whatever their language.

`_lt()` stores the text and translates it each time it is turned into a string, into the language
of that moment. A field's `string`, `help` and selection labels need neither: Odoo exports and
translates them as the field's own terms.

## Example

```python title="models/sale_order.py"
from odoo import _, fields, models

LATE = _("This order is late")


class SaleOrder(models.Model):
    _inherit = "sale.order"

    note = fields.Text(string=_("Note"))
```

```python title="models/sale_order.py"
from odoo import _lt, fields, models

LATE = _lt("This order is late")


class SaleOrder(models.Model):
    _inherit = "sale.order"

    note = fields.Text(string="Note")
```

## Suppressing

```python
LATE = _("This order is late")  # odooscan: ignore[OD132]
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
