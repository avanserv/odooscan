# OD607 private-rpc-method

An ORM call from JS names a method Odoo refuses to call over RPC.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Correctness | Error | all | no |

## What it reports

A call `orm.call(model, method, ...)`, or a legacy `_rpc({model, method})` or
`rpc.query({model, method})`, whose method is a literal Odoo refuses over RPC:

- a name starting with `_`, whatever the model;
- a method `BaseModel` makes private in the module's series, whatever the model, as listed in
  [OD313](OD313.md#what-it-reports): `init` from 10.0, and from 16.0 names such as `ensure_one`,
  `concat` and `union`, but for saas~16.1 to 16.4 and saas~17.1 to 17.3;
- with a literal model, `get_all` from saas~19.4 when a class in scope of the model, or of a model
  it inherits, is on `CachedModel`, and a method any such class decorates with `@api.private`;
- from 19.0, a method bound to no records: a class method, a static method, or a name bound to a
  call of `functools.partial`, `classmethod` or `staticmethod`, when every class in scope of the
  literal model, or of a model it inherits, that binds the name binds it so; when none binds it,
  `is_transient`, a class method of `BaseModel`, whatever the model. A `partialmethod` binds to the
  records. The call stays silent when a plain method of the name is on any such class or on a
  plain Python base of one, or when one of them has a base the scan cannot read or sits in a file
  that does not parse, as the scan does not order the classes the way Python looks them up. With a
  literal model, it stays silent too when a module in scope depends on one the scan does not index,
  which may bind the name to the records.

The model may be an expression such as `this.props.resModel`, which leaves the first two and
`is_transient`. Of the names `BaseModel` and `CachedModel` make private, a module of unknown series
is reported only for `init`, which nearly every series refuses: saas~19.1 to saas~19.3 accept
`get_all`. A module of unknown series is not reported for a method bound to no records, since a
series before 19.0 still calls it. 19.0 builds before March 2026 call it with the records as an
extra first argument, which [OD313](OD313.md#why-it-matters) explains, so they are reported too. A
`partial` is reported though Python 3.14 calls it, as the next section explains. The calls are
recognised as for [OD603](OD603.md), through `orm.silent` and `orm.cache()` too, in every script a
bundle loads but [test scripts](index.md#od6-javascript-and-owl).

## Why it matters

The server refuses to dispatch a method whose name starts with `_`, or one that any class of the
model's MRO decorates with `@api.private`, and answers with an `AccessError` the user sees as a
dialog, every time the call runs, even when the model has it. From 10.0 `init` is refused by name
until `@api.private` takes over. From 19.0 the server also refuses a method that is equal on the
model's class and on its records, as a class or a static method is. So is a `partial`
before Python 3.14, which binds one to the records like a method: the call works on 3.14 but not
on the older versions 19.0 and 20.0 support. Such a method is meant for Python callers only. The
usual cause is a client calling the helper behind a public method, or a record helper such as
`ensure_one`, rather than the public method or a new one the module adds to wrap it.

[OD604](OD604.md) leaves every call this rule reports to it, so a refused method the model does
not have is reported once, here.

## Example

```js title="static/src/js/post_button.js"
await this.orm.call("account.move", "_post", [[this.props.record.resId]]);
```

`_post` is the helper behind posting an entry: the method the client may call is `action_post`.

```js title="static/src/js/post_button.js"
await this.orm.call("account.move", "action_post", [[this.props.record.resId]]);
```

## Suppressing

```js
// odooscan: ignore[OD607]
await this.orm.call("account.move", "_post", [[this.props.record.resId]]);
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
