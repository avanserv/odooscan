# OD313 private-button-method

A button calls a method Odoo refuses to call.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Correctness | Error | all | yes |

## What it reports

A `<button type="object" name="x">` in a view arch, with a literal `name`, where:

- `x` starts with `_`, whether or not the model has it;
- `BaseModel` makes `x` private in the module's series, as the table lists;
- any class in scope of the model at the button's position, or of a model it inherits, decorates
  `x` with `@api.private`;
- from 19.0, `x` is bound to no records: a class method, a static method, or a name bound to a
  call of `functools.partial`, `classmethod` or `staticmethod`, when every class in scope of the
  model, or of a model it inherits, that binds the name binds it so; when none binds it,
  `is_transient`, a class method of `BaseModel`. A `partialmethod` binds to the records. The
  button stays silent when a plain method of the name is on any such class or on a plain Python
  base of one, or when one of them has a base the scan cannot read or sits in a file that does not
  parse, as the scan does not order the classes the way Python looks them up. It stays silent too
  when a module in scope depends on one the scan does not index, which may bind the name to the
  records.

| Series | Private methods of `BaseModel` |
| --- | --- |
| 10.0 on | `init` |
| 16.0, 17.0, saas~17.4 on | `concat`, `ensure_one`, `filtered`, `filtered_domain`, `flush_model`, `flush_recordset`, `invalidate_model`, `invalidate_recordset`, `mapped`, `new`, `sorted`, `union`, `with_company`, `with_context`, `with_env`, `with_prefetch`, `with_user` |
| 17.0, saas~17.4 on | `grouped` |
| 18.0 on | `sudo` |
| saas~18.2 on | `browse`, `check_access`, `exists`, `fetch`, `modified`, `search_fetch`, `update` |
| saas~18.3 on | `lock_for_update` |
| 19.0 on | `try_lock_for_update` |

When a class in scope of the model, or of a model it inherits, is on `CachedModel`, `get_all` is
private from saas~19.4. A module overriding one of these names is still reported, with or without
the decorator. A module of unknown series is reported only for `init`, which nearly every series
refuses: saas~19.1 to saas~19.3 have `CachedModel` without a private `get_all`. Nor is it
reported for a method bound to no records, since a series before 19.0 still calls it.

## Why it matters

Odoo calls a button through RPC, which refuses a private method. From saas~13.1 it checks a name
starting with `_` when it loads the view, so the module fails to install; before that, the button
fails when a user clicks it. A demo file differs: see [load
failures](https://avanserv.github.io/odooscan/rules/#load-failures). `@api.private` is in 16.0, 17.0
and from saas~17.4 on, not in saas~16.1 to 16.4 or saas~17.1 to 17.3, and is refused the same way,
on any override of the method. 16.0 and 17.0 gained it by a February 2025 backport, so an older
build accepts a button on `ensure_one`; the series cannot tell them apart, and the rule reports it.
From saas~18.3 the install check reads only the top override, and the click still refuses any.
`init` is refused from 10.0 on, by name until `@api.private` takes over, and 9.0 to 9.saas~11
refuse only the leading `_`.

From 19.0 the click also refuses a method that is equal on the model's class and on its records,
as a class or a static method is, while the install check reads only the leading `_` and
`@api.private`, so the module installs and the button fails every time a user clicks it. A
`partial` is refused the same way before Python 3.14, which binds one to the records like a
method: the button works on 3.14 but not on the older versions 19.0 and 20.0 support. 19.0 builds
before March 2026 call such a method with the records as an extra first argument: a class or a
static method that takes none, as `is_transient` does, raises a `TypeError`, and any other reads
the records in place of its first parameter, so the report holds there too.

The rule skips the same views and positions as [OD312](OD312.md), but not the modules it skips for
lack of classes: a leading `_`, a private method of `BaseModel`, or `get_all` on a model on
`CachedModel` tells the method is private without looking up the rest of the model. A method bound
to no records is read from the model's classes, and stays silent when a parent of one is hidden
from the scan or a module in scope depends on one outside the index.

## Example

```xml title="views/sale_order_views.xml"
<button type="object" name="_action_confirm" string="Confirm"/>
```

`_action_confirm` is private. Add a public method for the button to call.

```xml title="views/sale_order_views.xml"
<button type="object" name="action_confirm" string="Confirm"/>
```

```xml
<!-- odooscan: ignore[OD313] -->
```
