# OD313 private-button-method

A button calls a private method, which Odoo refuses.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Correctness | Error | all | yes |

## What it reports

A `<button type="object" name="x">` in a view arch, with a literal `name`, where `x` starts with
`_`, whether or not the model has it, or where any class in scope of the model at the button's
position, or of a model it inherits, decorates `x` with `@api.private`.

## Why it matters

Odoo calls a button through RPC, which refuses a private method. From saas~13.1 it checks a name
starting with `_` when it loads the view, so the module fails to install; before that, the button
fails when a user clicks it. `@api.private` exists from 16.0 and is refused the same way, on any
override of the method. From saas~18.3 the install check reads only the top override, and the click
still refuses any.

The rule skips the same views and positions as [OD312](OD312.md), but not the modules it skips for
lack of classes: a leading `_` tells the method is private without looking it up.

## Example

```xml title="views/sale_order_views.xml"
<button type="object" name="_action_confirm" string="Confirm"/>
```

`_action_confirm` is private. Add a public method for the button to call.

```xml title="views/sale_order_views.xml"
<button type="object" name="action_confirm" string="Confirm"/>
```
