# OD316 unknown-modifier-name

A view modifier names a field its model does not have.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Correctness | Error | 17.0 and later | yes |

## What it reports

A name in an `invisible`, `readonly`, `required` or `column_invisible` expression that is no field
of the model at the element's position, the view's or the comodel of the subview that encloses it.
`parent.x` reads the model one subview up, and `parent.x.y` is reported whatever `x` is, since Odoo
refuses a composed field there. Lowercase `true` and `false` inside an expression are names like any
other.

The names Odoo's view validation ignores, such as `context`, `uid` or `today`, and `id` are fine. So are `active_id`, `active_ids` and `active_model` before saas~17.1. Only the first name of
a path counts: `state.x` reads `state`.

## Why it matters

Odoo checks these names when it validates the view, so a misspelled one stops the install or the
upgrade of the module.

The rule stays silent when it cannot see every class or tell the model: a module whose dependencies
include one that is not indexed, a module that builds model names at runtime, a model that is
unknown or outside `depends`, a class with a plain Python base or an `_inherit` no indexed module
defines, and an element an xpath places in a position that only the parent view can tell. A field
that only a module outside `depends` adds is not reported, nor is `parent.x` outside any subview,
which Odoo ignores.

An element of an extension may land in a subview of the parent view, so it is also left alone when
a subview of the inheritance tree has the name, when a subview's model is unknown, and when the
tree is not fully indexed.

A subview that an extension puts inside a field of the parent view, by a `<field>` or an xpath spec,
is among those subviews rather than a position of its own. A name of its comodel is fine, a name of
the view's model is not reported, and a name of neither is reported against the view's model.

Syntax is [OD315](OD315.md)'s.

## Example

```xml title="views/sale_order_views.xml"
<field name="note" readonly="stat == 'done'"/>
```

`sale.order` has no `stat`, so the module fails to install.

```xml title="views/sale_order_views.xml"
<field name="note" readonly="state == 'done'"/>
```
