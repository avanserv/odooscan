# OD616 unknown-service

A script asks `useService()` for a service no script registers.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Correctness | Error | 17.0 and later | yes |

## What it reports

The key of each `useService("x")` call in a loaded script outside `static/tests`, when no script of
the modules in scope adds it to `registry.category("services")`. A key counts when a loaded script
outside `static/tests` adds it as a string literal, through `registry.category("services").add("x",
...)`, a chain of `.add()` on it, or a binding of the category. A service that only a module
missing from `depends` registers is reported too, naming that module. A module that Odoo always
installs with `base`, such as `web`, or auto-installs with the module, counts as in `depends`.

Modules before 17.0 are not checked, as for the other rules that read registry keys: 16.0 also adds
its legacy services to this registry under names only a run tells.

## Why it matters

The web client starts one service per key of the services registry, and `useService` throws
`Service x is not available` for any other, so the component fails to set up. Services are renamed
or replaced between series: 17.0 has an `rpc` service, while 18.0 exports `rpc` as a function from
`@web/core/network/rpc`.

The rule stays silent for a service that a script of the module outside `static/tests` tests for
with `"x" in env.services` or `"x" in this.env.services`, since the code then expects it may be
missing. It is silent too for a module whose dependencies include one that is not indexed, such as
an Enterprise module, and when a script in scope adds a key to the services registry that only a
run tells. A service read through `env.services.x` is not checked.

## Example

```js title="static/src/stock_panel.js"
import { Component } from "@odoo/owl";
import { useService } from "@web/core/utils/hooks";

export class StockPanel extends Component {
    static template = "stock_panel.StockPanel";
    static props = {};

    setup() {
        this.rpc = useService("rpc");
    }

    async load() {
        return this.rpc("/stock_panel/data");
    }
}
```

18.0 has no `rpc` service: import the function instead.

```js title="static/src/stock_panel.js"
import { Component } from "@odoo/owl";
import { rpc } from "@web/core/network/rpc";

export class StockPanel extends Component {
    static template = "stock_panel.StockPanel";
    static props = {};

    async load() {
        return rpc("/stock_panel/data");
    }
}
```

## Suppressing

```js
// odooscan: ignore[OD616]
this.rpc = useService("rpc");
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
