# OD129 auth-none-user

An auth='none' route reads the user or writes records, but runs with no user.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Security | Warning | all | no |

## What it reports

An `@http.route` with `auth="none"`, its own or, when it leaves `auth` out and the scan reads the
class it extends as [OD127](OD127.md) says, that of the route it overrides, whose body reads
`request.env.user`, or calls `write()`, `create()` or `unlink()` on records, as OD127 reads them. It
stays silent when the body sets a user, with `request.update_env(user=...)`,
`request.session.authenticate()` (from 20.0 `authenticate(request.session, ...)`), an
`_auth_method_*()` call other than `_auth_method_none()` (which clears the user),
`request.uid = ...` or `request.env = request.env(user=...)`. A write on records built for a user,
with `with_user()`, `request.env(user=...)` or `api.Environment(cr, uid, ...)`, is not reported
either. A `None` user passed to `request.update_env()` or `api.Environment()` sets none, so it does
not count; passed to `with_user()` or an environment call, it keeps the user of what it is called
on. Only the route's own body is read, with the functions it nests.

## Why it matters

`auth="none"` runs the route in an environment without a user, whether the visitor is signed in
or not: `request.env.uid` is `None` and `request.env.user` is an empty recordset. Code that reads
the user's company, partner or language gets nothing, and a record it writes has no author, under
access rights that belong to no one. `auth="none"` is meant for routes that need no database
user, such as those that run before a database is picked.

Use `auth="public"` for a route that anyone may call but that works with records: Odoo then runs
it as the signed-in user, or as the public user of the website for a visitor. If the route
authenticates its caller itself, set the user with `request.update_env(user=...)` before it reads
or writes.

## Example

```python title="controllers/main.py"
class GreetingController(http.Controller):
    @http.route("/my/greeting", type="http", auth="none")
    def greeting(self):
        return f"Hello {request.env.user.name}"
```

The page greets nobody by name, signed in or not.

```python title="controllers/main.py"
class GreetingController(http.Controller):
    @http.route("/my/greeting", type="http", auth="public")
    def greeting(self):
        return f"Hello {request.env.user.name}"
```

A signed-in user is greeted by name, a visitor as the public user.

## Suppressing

```python
def greeting(self):  # odooscan: ignore[OD129]
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
