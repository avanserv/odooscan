# OD705 open-redirect-flow

Data a user controls picks the site a redirect sends the browser to.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Security | Warning | all | no |

## What it reports

A value from a [source](https://avanserv.github.io/odooscan/rules/#od7-data-flows) that reaches the
URL of `werkzeug.utils.redirect()` or `werkzeug.redirect()`, or of `request.redirect()` and
`request.redirect_query()` called with `local=False`. From 16.0 `request.redirect()` drops the
scheme and the host of the URL unless `local` is false, and strips leading slashes and backslashes,
so a call that leaves `local` true is not reported. 15.0 strips only slashes, so `/\evil.example`,
which browsers read as `//evil.example`, keeps its host; before 15.0 there is no `local` at all. On
15.0 and before, every tainted URL is reported. A 16.0 older than the October 2024 fix that added the
backslash strip, and saas~16.1-16.4, saas~17.1 and saas~17.3, strip only slashes too but are read as
16.0.

A URL whose start the code picks keeps the host the code chose and is not reported: one built by
an f-string, `+`, `%` or a literal's `format()` that starts with a path such as `/shop/`, with
`scheme://host/`, with a literal holding `?` or `#`, or with a value the user does not control. So
is a URL checked by `startswith()` with such a prefix, one passed through `urlencode()` or
`url_encode()`, and portal's `_build_url_w_params(url, params)` on such a URL, which encodes the
params into the query. A lone `/` is no such start: `//evil.example` is a URL on another host.

## Why it matters

A link to the site that redirects to a page of the attacker's borrows the site's name: the victim
trusts the address they clicked, and lands on a copy of the login page that collects their
password. No code runs on the server, which is why the rule warns rather than errors.

## Example

```python title="controllers/main.py"
class ShopLogin(http.Controller):
    @http.route("/shop/login/done", type="http", auth="user")
    def done(self, redirect="/shop"):
        return werkzeug.utils.redirect(redirect)
```

`/shop/login/done?redirect=https://evil.example` sends the user to another site.

```python title="controllers/main.py"
class ShopLogin(http.Controller):
    @http.route("/shop/login/done", type="http", auth="user")
    def done(self, redirect="/shop"):
        return request.redirect(redirect)
```

From 16.0 `request.redirect()` drops the scheme and the host of the URL, and the leading slashes
and backslashes, so the user stays on the site.

## Suppressing

```python
return werkzeug.utils.redirect(url)  # odooscan: ignore[OD705]
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
