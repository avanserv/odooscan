# OD609 unescaped-markup

Owl's `markup()` receives a value built at runtime, which `t-out` renders unescaped.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Security | Info | all | no |

## What it reports

A call `markup(x)` or `owl.markup(x)` whose argument is not a constant, in every script a bundle
loads but those under `static/tests`. A constant is a string, a template whose every `${}` holds a
constant, `+` of constants, a conditional `c ? a : b` between two constants, or `_t()` of
constants. The tagged form, `` markup`<b>${name}</b>` ``, is not reported:
it escapes each placeholder. This is a hotspot: code to review, not a confirmed flaw.

## Why it matters

`markup()` called as a function wraps its argument as it is, and `t-out` then renders it as HTML
rather than text. When any part of the value comes from a record or a user, such as a field the
user typed in, an `onerror` or `onclick` attribute in it runs as script in the browser of whoever
opens the view (cross-site scripting), with that user's session. The server cleans the value of an
`Html` field when it is written, unless the field sets `sanitize=False`, but never a `Char` or
`Text` field, a name, a URL parameter or an RPC result. The finding asks for the source of the value to be confirmed, or for the value to be
escaped.

[OD703](OD703.md) reports the same mistake in Python, on `Markup()` given data a route receives.

## Example

```js title="static/src/note_field.js"
get noteHtml() {
    return markup(`<p class="o_note">${this.props.record.data.note}</p>`);
}
```

A note containing `<img src=x onerror=alert(1)>` runs the script for every user who opens the
record.

```js title="static/src/note_field.js"
get noteHtml() {
    return markup`<p class="o_note">${this.props.record.data.note}</p>`;
}
```

The tagged template escapes the note, so it shows as text inside the paragraph.

## Suppressing

```js
// odooscan: ignore[OD609]
return markup(this.props.record.data.body_html);
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
