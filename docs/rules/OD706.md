# OD706 server-request-forgery-flow

Data a user controls picks the URL the server sends a request to.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Security | Error | all | no |

## What it reports

A value from a [source](https://avanserv.github.io/odooscan/rules/#od7-data-flows) that reaches
the URL of `requests.get()`, `post()`, `put()`, `patch()`, `delete()`, `head()`, `options()` or
`request()`, on the module or on a session, or of `urllib.request.urlopen()`.

A URL whose start the code picks keeps the host the code chose and is not reported, as for
[OD705](OD705.md): one built by an f-string, `+`, `%` or a literal's `format()` that starts with
`scheme://host/`, a path, a literal holding `?` or `#`, or a value the user does not control, or
one checked by `startswith()` with such a prefix.

## Why it matters

The server sends the request from inside the network, with the server's address. A user who picks
the URL reaches what the firewall keeps from them: the cloud provider's metadata service, which
hands out credentials, an admin interface bound to localhost, or another database server. The
response, or how long it takes, tells them what is there.

## Example

```python title="controllers/main.py"
class Preview(http.Controller):
    @http.route("/shop/preview", type="json", auth="user")
    def preview(self, url):
        return requests.get(url, timeout=10).text
```

`url` may be `http://169.254.169.254/latest/meta-data/`.

```python title="controllers/main.py"
class Preview(http.Controller):
    @http.route("/shop/preview", type="json", auth="user")
    def preview(self, product_code):
        return requests.get(f"https://catalog.example.com/products/{product_code}", timeout=10).text
```

The code picks the host; the user picks only the product.

## Suppressing

```python
response = requests.get(url, timeout=10)  # odooscan: ignore[OD706]
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
