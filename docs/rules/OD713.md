# OD713 method-injection-flow

Data a user controls names the method that getattr() looks up and the code calls.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Security | Error | all | no |

## What it reports

A value from a [source](https://avanserv.github.io/odooscan/rules/#od7-data-flows) that names the
attribute of `getattr(obj, name)` when the code calls what it returns, as
`getattr(records, name)()`, with or without `sudo()`.

A name built with text the code writes that holds a letter or a digit is not reported, as
`"_get_%s_view" % name`, `name + "_rate"`, `f"action_{name}"` or `"x_{}".format(name)`: the user
picks from a family of methods the code chose. `"_" + name` is reported, since it names any private
method.

## Why it matters

Over RPC, Odoo refuses a method whose name starts with `_` or that `@api.private` marks, so a user
calls only the public ones, each with the user's rights. A call through `getattr()` skips that
check: the user runs any method of the object with the arguments the code passes, such as
`unlink()`, `sudo()` or a private step that a public method guards.

## Example

```python title="controllers/main.py"
class Orders(http.Controller):
    @http.route("/shop/order/run", type="json", auth="user")
    def run(self, order_id, action):
        order = request.env["sale.order"].browse(int(order_id))
        return getattr(order, action)()
```

`action` may be `_action_confirm`, which confirms the order without the checks of
`action_confirm()`.

```python title="controllers/main.py"
class Orders(http.Controller):
    @http.route("/shop/order/run", type="json", auth="user")
    def run(self, order_id, action):
        order = request.env["sale.order"].browse(int(order_id))
        return getattr(order, f"action_{action}")()
```

The user now picks among the `action_` methods, which are public and check the user's rights.

## Suppressing

```python
return getattr(order, action)()  # odooscan: ignore[OD713]
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
