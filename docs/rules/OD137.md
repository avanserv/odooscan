# OD137 write-in-loop

A loop over records writes the same values to each record where one write() would do.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Performance | Info | all | no |

## What it reports

A call to `write()` on the record a `for` loop over records takes, directly or through `sudo()`,
`with_context()`, `with_company()`, `with_user()` or `with_env()`, whose arguments name nothing the
loop binds. The loop, its records and the cases it stays silent on are those of [OD134](OD134.md),
but the model: the write is on the record itself.

A write of values read from the record, such as `line.write({"name": line.product_id.name})`, of a
dict the loop fills from it, or of a call that may return a new value each time, such as a sequence
number from `next_by_code()` or a token from `uuid4()`, is not reported, since one write would give
every record the same. A call that returns the same value on each pass does not prevent a report:
`fields.Datetime.now()`, `fields.Date.today()`, `context_today()`, `_()`, `env.ref()`, and
`Command.link()`, `unlink()`, `set()` or `clear()`.

## Why it matters

A `write()` on many records updates them in one `UPDATE` per hundred rows (18.0 `odoo/models.py`,
20.0 `odoo/orm/models.py`, `_write_multi()`), and checks access and marks the fields to recompute
once for them all. Writing the same values record by record does each of these once per record. A
condition on the record becomes a `filtered()` before one write.

## Example

```python title="models/sale_order.py"
class SaleOrder(models.Model):
    _inherit = "sale.order"

    def action_x_close_lines(self):
        for line in self.order_line:
            if line.qty_delivered >= line.product_uom_qty:
                line.write({"x_closed": True})
```

```python title="models/sale_order.py"
class SaleOrder(models.Model):
    _inherit = "sale.order"

    def action_x_close_lines(self):
        self.order_line.filtered(lambda line: line.qty_delivered >= line.product_uom_qty).write({"x_closed": True})
```

## Suppressing

```python
line.write({"x_closed": True})  # odooscan: ignore[OD137]
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
