# OD128 cors-any-origin

A route sets cors='*', so a script on any site can read its responses.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Security | Info | all | no |

## What it reports

An `@http.route` whose `cors` is the literal `"*"`, whatever its type and `auth`. This is a
hotspot: code to review, not a confirmed flaw.

## Why it matters

Odoo answers such a route with `Access-Control-Allow-Origin: *`, which tells the browser that a
script of any site may read the response. Odoo sends no `Access-Control-Allow-Credentials`, so the
browser leaves the session cookie out of such a request: what the script reads is what an
anonymous visitor gets. That is harmless for data meant for everyone, and it still matters in two
cases. A server on a private network, such as an IoT box or an Odoo reachable only from the
office, answers the browser of anyone inside it, so any site that person opens can read the
route's responses from within the network. And a route with `auth="public"` or `auth="none"`
answers that script with whatever it gives a visitor.

When a known application calls the route, name its origin instead, so that the browser refuses
the response to every other site.

## Example

```python title="controllers/main.py"
class CatalogController(http.Controller):
    @http.route("/shop/prices", type="jsonrpc", auth="public", cors="*")
    def prices(self):
        domain = [("is_published", "=", True)]
        return request.env["product.template"].search_read(domain, ["name", "list_price"])
```

A script on any site the visitor opens reads the prices, and on an Odoo reachable only from the
office, what an outside visitor could not reach.

```python title="controllers/main.py"
class CatalogController(http.Controller):
    @http.route("/shop/prices", type="jsonrpc", auth="public", cors="https://shop.example.com")
    def prices(self):
        domain = [("is_published", "=", True)]
        return request.env["product.template"].search_read(domain, ["name", "list_price"])
```

Before saas~18.1 the type is `json`.

## Suppressing

```python
@http.route("/shop/prices", type="jsonrpc", auth="public", cors="*")  # odooscan: ignore[OD128]
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
