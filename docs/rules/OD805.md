# OD805 template-stale-message

A module's .pot template keeps a Python message no call of the module has.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Quality | Info | all | no |

## What it reports

An entry of a module's `i18n/<module>.pot` template whose references all name `.py` files of the
module, such as `code:addons/sale_kiosk/models/sale_order.py:0`, without the `odoo-javascript`
comment, and whose message no `_()` or `_lt()` call of the module has. A message counts as had
when any extractor of any series may take it, such as the strings of a parenthesis Odoo's own
extractor reads as a call, or a constant f-string.

An entry is not reported when one of its references names a `.py` file the scan does not read,
such as one under `static/` or one whose coding comment names an encoding other than UTF-8. A
module with a `.py` file that does not parse, that is not UTF-8 and has no coding comment, or of a
series on Python 2, gets no finding: its messages are not all known.

## Why it matters

Translators work through every entry of the template, and the `.po` files merged from it keep the
message after the code dropped it. Their work on it is lost: no call asks for it. A template that
keeps such messages was exported before the code changed.

## Example

```po title="i18n/sale_kiosk.pot"
#. module: sale_kiosk
#. odoo-python
#: code:addons/sale_kiosk/models/sale_order.py:0
msgid "The kiosk is closed"
msgstr ""
```

```python title="models/sale_order.py"
from odoo import _, models


class SaleOrder(models.Model):
    _inherit = "sale.order"

    def action_kiosk(self):
        return _("The kiosk is open")
```

Export the template again, which writes the message the code has instead:

```po title="i18n/sale_kiosk.pot"
#. module: sale_kiosk
#. odoo-python
#: code:addons/sale_kiosk/models/sale_order.py:0
msgid "The kiosk is open"
msgstr ""
```

## Suppressing

```po
# odooscan: ignore[OD805]
#. module: sale_kiosk
#. odoo-python
#: code:addons/sale_kiosk/models/sale_order.py:0
msgid "The kiosk is closed"
msgstr ""
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
