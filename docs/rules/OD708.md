# OD708 command-injection-flow

Data a user controls reaches a command the server runs through the shell.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Security | Error | all | no |

## What it reports

A value from a [source](https://avanserv.github.io/odooscan/rules/#od7-data-flows) that reaches
the command of `os.system()`, `os.popen()`, `subprocess.getoutput()` or
`subprocess.getstatusoutput()`, or of `subprocess.run()`, `call()`, `check_call()`,
`check_output()` and `Popen()` called with `shell=True`, by keyword or position. Without
`shell=True` these take a list of arguments and run no shell, so they are not reported.

A value passed through `shlex.quote()`, or a list passed through `shlex.join()`, is harmless for
this rule: the shell reads each value they quote as one word, whatever it holds.

## Why it matters

The shell reads `;`, `|`, `&&`, `$(...)` and backquotes in the command, so a user who picks part
of it runs any command they like as the user of the server: they read the configuration file with
the database password, write to the filestore, or open a connection back to their own machine.

## Example

```python title="controllers/main.py"
class Labels(http.Controller):
    @http.route("/shop/label", type="http", auth="user")
    def label(self, name):
        subprocess.run(f"lpr -T {name} /tmp/label.pdf", shell=True, check=True)
```

`name` may be `x; rm -rf ~`.

```python title="controllers/main.py"
class Labels(http.Controller):
    @http.route("/shop/label", type="http", auth="user")
    def label(self, name):
        subprocess.run(["lpr", "-T", name, "/tmp/label.pdf"], check=True)
```

The list runs `lpr` with `name` as one argument, and no shell reads it.

## Suppressing

```python
subprocess.run(command, shell=True)  # odooscan: ignore[OD708]
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
