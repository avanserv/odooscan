# OD304 unknown-view-field

A view references a field its model does not have.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Correctness | Error | all | yes |

## What it reports

A `<field>` in a view's arch whose name is not a field of the model at that place: the view's
model, or inside an x2many field's subview, that field's comodel. It also reports a field that only
a module missing from `depends` adds. For an inherited view without a `model`, the model is the
parent view's. A module that Odoo always installs with `base`, such as `web`, counts as in
`depends`.

## Why it matters

Odoo validates every view when it loads it, and a field the model does not have stops the install
with `Field "x" does not exist in model "y"`. When the field comes from a module outside
`depends`, the view validates where that module is installed and breaks where it is not. The cause
is usually a typo, or a field renamed in a new series.

A `<field>` used as a locator, with a `position` attribute, finds an element of the parent view
instead of adding one, and [OD310](OD310.md) checks it. The rule skips a place whose model it
cannot tell, such as the inside of a spec on a `list` or `kanban` element, which may land in the
main view or in any subview, and views on a model no indexed module defines.

## Example

```xml title="views/sale_order_views.xml"
<record id="view_order_form_customer_ref" model="ir.ui.view">
    <field name="name">sale.order.form.customer.ref</field>
    <field name="model">sale.order</field>
    <field name="inherit_id" ref="sale.view_order_form"/>
    <field name="arch" type="xml">
        <field name="payment_term_id" position="after">
            <field name="customer_reference"/>
        </field>
    </field>
</record>
```

`sale.order` has no `customer_reference` field; the customer's reference is `client_order_ref`.

```xml title="views/sale_order_views.xml"
<record id="view_order_form_customer_ref" model="ir.ui.view">
    <field name="name">sale.order.form.customer.ref</field>
    <field name="model">sale.order</field>
    <field name="inherit_id" ref="sale.view_order_form"/>
    <field name="arch" type="xml">
        <field name="payment_term_id" position="after">
            <field name="client_order_ref"/>
        </field>
    </field>
</record>
```
