# OD507 license-missing

The manifest names no license, which Odoo reads as LGPL-3.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Quality | Warning | all | no |

## What it reports

A manifest without a `license` key, or one whose `license` is empty, `False` or `None`. The first is
reported where the manifest opens, at its dict or at the list, tuple or set of key and value pairs
that stands for one, and the second at the value.

## Why it matters

Odoo records the license of each module in the apps list, and takes LGPL-3 for a module that
names none. A proprietary module then claims an open license it was never released under, and an
AGPL one the weaker terms of the LGPL. From saas~14.5 Odoo also logs, for a module in the
`library_loan` directory, ``Missing `license` key in manifest for 'library_loan', defaulting to
LGPL-3`` each time it reads the manifest.

Before saas~14.5, LGPL-3 stands in only for a missing key. An empty `license`, `False` or `None`
is stored as no license, so the apps list shows no license for the module at all.

## Example

```python title="__manifest__.py"
{
    "name": "Library loans",
    "version": "18.0.1.0.0",
    "depends": ["base"],
}
```

The module gets LGPL-3 whatever its authors meant. Name the license:

```python title="__manifest__.py"
{
    "name": "Library loans",
    "version": "18.0.1.0.0",
    "depends": ["base"],
    "license": "OPL-1",
}
```
