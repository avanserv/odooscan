# OD000 syntax-error

The file does not parse.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Correctness | Error | all | no |

## What it reports

A Python file that is not valid Python, an XML file that is not well-formed XML, or a CSV data
file whose header row cannot be read. The finding points at the first error the parser meets, and
its message is the parser's own. Nothing else is checked in that file, so fixing it can bring other
findings to light.

## Why it matters

Odoo imports a module's Python package when it loads the module, and a `SyntaxError` in any file
the package imports stops the load: the module cannot be installed, and a database that already has
it fails to start. An XML or CSV data file is parsed when the module is installed or updated, and a
parse error stops that install or update.

An empty XML file is not reported. A file that is not valid UTF-8 is not read at all, so it gets
no finding. A `__manifest__.py` that does not parse is not reported either: without a readable
manifest, odooscan does not treat the directory as a module. The CSV reader is lenient and reads
a row with an unclosed quote or a missing column as best it can.

## Example

```xml title="views/sale_order_actions.xml"
<odoo>
    <record id="action_small_orders" model="ir.actions.act_window">
        <field name="name">Small orders</field>
        <field name="res_model">sale.order</field>
        <field name="domain">[('amount_total', '<', 100)]</field>
    </record>
</odoo>
```

A bare `<` opens a tag in XML, so the domain's comparison breaks the file.

```xml title="views/sale_order_actions.xml"
<odoo>
    <record id="action_small_orders" model="ir.actions.act_window">
        <field name="name">Small orders</field>
        <field name="res_model">sale.order</field>
        <field name="domain">[('amount_total', '&lt;', 100)]</field>
    </record>
</odoo>
```

## Suppressing

Fix the file instead: while it does not parse, no other rule sees it. To leave out a file that is
not meant to parse, such as a template a script fills in, exclude it:

```sh
oscn check . --exclude scaffold/
```

See [suppressing a finding](https://github.com/avanserv/odooscan#suppressing-a-finding).
