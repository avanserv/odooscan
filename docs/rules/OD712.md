# OD712 sudo-model-injection

Data a user controls picks the model of records read or written as superuser.

| Category | Severity | Series | Needs the index |
| --- | --- | --- | --- |
| Security | Error | all | no |

## What it reports

A value from a [source](https://avanserv.github.io/odooscan/rules/#od7-data-flows) that names the
model of `env[name]` or `env.get(name)`, when those records are searched, read, grouped, mapped,
created, written or unlinked under `sudo()`: by a method whose name starts with `search`, or by
`read()`, `read_group()`, `_read_group()`, `formatted_read_group()`, `mapped()`, `create()`,
`write()` or `unlink()`. The records stay those of the model the user picks through `sudo()` and
the other methods that change the environment, `browse()`, `exists()`, `filtered()` and the locals
bound to them.
[What runs as superuser](https://avanserv.github.io/odooscan/rules/#od7-data-flows) lists the
forms besides `sudo()`.

A test that the name is in `env`, as `if model not in request.env: raise`, proves only that the
model exists: the user still picks which one. Records outside `sudo()` are not reported, as the
user's access rights bound what they reach; nor are other methods, such as the access helpers that
check the user's rights to the records they are called on.

## Why it matters

`sudo()` lifts the access rights, the record rules and the field groups. A route meant for the
records of one model then reads or changes those of any: the values of `ir.config_parameter`, the
keys of a payment provider, or the users of `res.users`.

## Example

```python title="controllers/main.py"
class Labels(http.Controller):
    @http.route("/shop/label", type="json", auth="user")
    def label(self, model, res_id):
        record = request.env[model].sudo().browse(int(res_id))
        return record.read(["display_name"])
```

`model` may be `ir.config_parameter`, whose values the user then reads by id.

```python title="controllers/main.py"
class Labels(http.Controller):
    _MODELS = ("product.template", "blog.post")

    @http.route("/shop/label", type="json", auth="user")
    def label(self, model, res_id):
        if model not in self._MODELS:
            raise NotFound()
        record = request.env[model].browse(int(res_id))
        record.check_access("read")
        return record.sudo().read(["display_name"])
```

On 16.0 and 17.0, which have no `check_access()`, call `check_access_rights("read")` and
`check_access_rule("read")`.

## Suppressing

```python
return record.read(["display_name"])  # odooscan: ignore[OD712]
```

See [suppressing a finding](https://avanserv.github.io/odooscan/suppressing/).
